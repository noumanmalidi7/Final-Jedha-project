Plan Synthétique - Score d'Impact Environnemental de l'Assiette Mondiale
Phase 1 : Récupération & Exploration Initiale (Semaine 12-23/01)
1. Récupération de Données (4h)
Datasets principaux : Environment Impact of Food Production + World Food/Feed Production
Enrichissement via API Banque Mondiale : PIB/habitant, taux d'urbanisation par pays
Web Scraping optionnel : Données de régimes alimentaires spécifiques par région (sources FAO, Our World in Data)
Documentation : Sources, licences, métadonnées de chaque dataset
2. Exploration Naïve (4h)
Dimensions & Poids : Nb lignes/colonnes, stockage, empreinte mémoire
Qualité : Duplicatas, valeurs nulles, colonnes vides, outliers (%)
Analyse descriptive : Types de variables, distributions, cardinalités
Architecture données :
Tables de fait : Production alimentaire par pays/année, Impact par aliment
Tables de dimension : Pays, Aliments, Années
Système : OLAP (analyse multidimensionnelle)
Variable cible : Empreinte carbone totale (kg CO₂eq) ou hydrique (L) par pays
Type ML : Régression (prédiction impact) + Clustering (profils pays)
Modèles pressentis : RandomForest, XGBoost, KMeans, DBSCAN
Phase 2 : Architecture & Traitement (Mars)
3. Schéma Base de Données (1h)
DBDiagram : Modélisation étoile/flocon
Tables :
Fait_Production (pays_id, aliment_id, année, tonnes_produites)
Fait_Impact (aliment_id, co2_kg, eau_litres, land_m2)
Dim_Pays (pays_id, nom, pib, urbanisation, region)
Dim_Aliments (aliment_id, nom, catégorie)
4. Data Lake & Data Warehouse (2h)
Data Lake : Stockage brut (CSV/Parquet) dans PostgreSQL ou DuckDB
Data Warehouse : Tables structurées post-ETL (système OLAP optimisé pour requêtes analytiques)
5. Pipeline ETL (4h)
Extraction : Lecture depuis Data Lake
Transformation :
Jointure Impact × Production (normalisation tonnes → kg)
Calcul impact total : tonnes_produites × 1000 × co2_par_kg
Gestion nulls (imputation/suppression), outliers (IQR/Z-score)
Agrégation par pays/année
Chargement : Ingestion vers Data Warehouse
Script Python : Conversion notebook → etl_pipeline.py réutilisable
Phase 3 : Analyse & Modélisation (Mars)
6. EDA Approfondie (8h)
Univariée : Distribution impact par type d'aliment, production par pays
Bivariée : Corrélation PIB vs empreinte carbone, urbanisation vs consommation viande
Multivariée : Heatmap corrélations, PCA pour réduction dimensionnelle
Tests statistiques : ANOVA (différences régions), Pearson/Spearman
Hypothèses :
H1 : Pays riches = + forte empreinte animale
H2 : Urbanisation ↑ = Consommation viande ↑
Conclusion : Variables retenues pour ML (impact aliments, PIB, production céréales/viande)
7. Machine Learning (6h)
Preprocessing :
Features : Production par catégorie, PIB, urbanisation, régime alimentaire
Target : Empreinte carbone/hydrique totale
Train/Test split (80/20), validation croisée
Encodage catégories (OneHot), standardisation (StandardScaler)
Modèles Régression : RandomForest, XGBoost, Ridge
Modèles Clustering : KMeans (profils pays), Hierarchical Clustering
Évaluation : RMSE, R², MAE / Silhouette Score
Fine-tuning : GridSearchCV, hyperparamètres optimaux
MLFlow : Tracking expériences, versioning modèles
Sauvegarde : joblib.dump(model, 'model_impact.pkl')
Phase 4 : Déploiement & Présentation (Mars)
8. Application Streamlit (6h)
Fonctionnalités :
Simulateur Menu : L'utilisateur sélectionne aliments + quantités → calcul impact
Comparateur Pays : Visualisation empreinte par pays/région
Prédiction : "Si +10% viande, impact carbone augmente de X%"
Clustering : Affichage profils pays (visualisation 2D/3D)
Intégration : Chargement modèles via joblib, connexion Data Warehouse
Visualisations : Graphiques interactifs (Plotly/Altair)
Déploiement : Streamlit Cloud / Heroku / Render
9. Git & Versioning
Structure repo :
/data (raw, processed)
/notebooks (EDA, ML)
/scripts (etl_pipeline.py, train_model.py)
/app (streamlit_app.py)
/models (fichiers .pkl)
README.md, requirements.txt, .gitignore
MLFlow : Tracking dans /mlruns, serveur local ou distant
10. Présentation Demo Day (4h)
PowerPoint :
Problématique & enjeux
Pipeline données (schéma)
Insights EDA (3-4 graphiques clés)
Résultats ML (métriques, importance features)
Démo Streamlit live
Script oral : 15-20 min, répétition
README Github : Installation, utilisation, résultats, captures écran
